# Taller Práctico: Estructura Básica del Frontend con HTML y CSS

Repositorio correspondiente al taller práctico de introducción al desarrollo frontend: **Identificar la estructura básica del frontend mediante HTML, organizando correctamente los elementos de una página web.**

---

## 📋 Descripción del Proyecto

Este proyecto consiste en una página web personal estructurada semánticamente con **HTML5** y estilizada mediante **CSS3**. Se diseñó aplicando separación de responsabilidades (*Separation of Concerns*), manteniendo la estructura independiente del diseño visual.

### Contenidos y Etiquetas Implementadas

- **Estructura base del documento:** `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`.
- **Encabezados jerárquicos:** `<h1>`, `<h2>`, `<h3>` para una clara jerarquía visual y de accesibilidad.
- **Párrafos de texto:** `<p>`, `<strong>`, `<em>` para presentación personal y descripciones.
- **Listas desordenadas y elementos:** `<ul>`, `<li>` para listar áreas de interés, lecturas recomendadas y enlaces.
- **Multimedia e hipervínculos:**
  - `<img>` con atributos descriptivos (`alt`, `src`) para el avatar de perfil.
  - `<a>` con atributos seguros (`target="_blank"`, `rel="noopener noreferrer"`) para sitios favoritos externos.

## 🎨 Características de Diseño (CSS)

- **Diseño Responsivo:** Adaptable a dispositivos móviles y escritorios mediante Grid y Flexbox.
- **Efectos y Microinteracciones:** Transiciones suaves (`transition`), efectos hover en tarjetas y enlaces, sombras profundas y esquinas redondeadas.
- **Tipografía Editorial:** Importación de fuentes tipográficas (*Cinzel* para encabezados y *Plus Jakarta Sans* para lectura vía Google Fonts).
- **Paleta de Colores Natural y Orgánica:** Variables CSS (`:root`) con estética inspirada en el arte y tinta *sumi-e* de *Vagabond* (tonos carbón profundo, pergamino cálido, terracota y ocres naturales).
